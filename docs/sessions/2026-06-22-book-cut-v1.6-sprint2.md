## A4 `_resolve_outline_source` 单 PDF 双调（commit `aebd889`）

**问题**：`_resolve_outline_source` 在单 PDF 路径上仍调 `_first_and_count_pdfs`（`os.scandir` × 1），
随后又被 `run_pipeline` 主循环再扫一次（`Path(output).iterdir()` × 1）。
多 PDF 时 `_first_and_count_pdfs` 还会遍历整个 `input_dir`。

**修复**：把"取所有 PDF 文件列表"集中到 `_resolve_outline_source` 一次，
返回 `list[Path]`；主循环直接复用，**单 PDF 路径零额外 IO**，多 PDF 路径不再二次扫描。

```python
def _resolve_outline_source(input_path, output_dir) -> list[Path] | None:
    if input_path.is_dir():
        # 多 PDF → 列出所有 PDF（一次 scandir）
        pdfs = _first_and_count_pdfs(input_path)[0]
        return pdfs if pdfs else None
    elif input_path.is_file() and input_path.suffix.lower() == ".pdf":
        return [input_path]  # 单 PDF → 一次 list wrap，无 IO
    return None
```

## A5 deskew projection 降分辨率（commit `aebd889`）

**问题**：`_detect_angle_projection`（`preprocess/deskew.py`）粗搜 21 角度 + 精搜 21 角度，
每次 warpAffine 全尺寸。4000² 像素图：~21×2 = 42 次 warpAffine，每次 ~5ms → 总 **194ms**。

**修复**：投影只关心 row sum 形状，不需像素精度。先 `cv2.resize` 到 short 边 = 1000，
再 warpAffine。1000² warpAffine ~0.1ms → 总 **21ms**。

```python
if downsample > 0 and max(h, w) > downsample:
    scale = downsample / max(h, w)
    binary = cv2.resize(binary, (max(1, int(w*scale)), max(1, int(h*scale))),
                        interpolation=cv2.INTER_AREA)
```

实测：`ZHSY100456` 4000² 输入，deskew projection 从 **194ms → 21ms（9.3× speedup）**。
精度：±0.1°（精搜步长），与全尺寸完全一致。

API：`downsample <= 0` 或 `downsample >= max(h, w)` → 保留 v1.5 行为（不缩）。

## A3 split/crop border 复用 Hough（commit `e45ab60`）

**问题**：`--split border --crop border` 时，pipeline 跑两次 Hough：
1. `split_border_from_array`：找全图外框 + split x
2. `crop_to_border_from_array` × 2：每个子图再跑一次 Hough 找自己的版框

两次 Hough 都做 Canny + HoughLinesP + cluster_lines，每次 ~4ms → 流水线浪费 ~8ms / 双页。

**修复**：让 split_border 一次 Hough 同时返回 sub_arrs + 每页 page_rect，crop 直接用 rect。

### 新 API

```python
@dataclass
class SplitBorderResult:
    sub_arrays: list[np.ndarray]
    page_rects: list[tuple[int, int, int, int] | None]  # 子图坐标系

def split_border_with_rects_from_array(arr) -> SplitBorderResult:
    """版框切分 + 每页版框 rect（crop 复用 Hough）"""

def crop_to_border_from_array(arr, ..., page_rect=None) -> Image.Image:
    """page_rect 提供时跳过 Hough，直接裁切"""
```

### 关键设计

1. **CROP preset 替代 SPLIT preset**（`HOUGH_PRESET_CROP_BORDER` threshold=60 vs `SPLIT_BORDER` 80）
   - A3 用一次 Hough 同时找"外框（给 split）" + "每页内框（给 crop）"
   - SPLIT 太严会漏掉每页的细版框边 → page_rect 比 crop 自跑 Hough 窄（ZHSY page 10 早期 19px diff）
   - CROP 较松，能同时找到外框 + 每页内框，差异降到 1-2px（Hough 自然方差）

2. **`page_rect` 退化兜底**（`split/border.py::_derive_page_rects`）
   - 用**子图宽度**（不是全图宽度）做 `min_dim = max(20, int(sub_w * 0.2))` 阈值
   - 兜底：rect 宽度 < 子图宽度 50% → 返回 `None` → crop 自跑 Hough
   - 原因：古籍靠页边的细线在全图 cluster 里被并入邻居，rect 太窄不如让 crop 跑自己的 Hough

3. **接口向后兼容**
   - `crop_to_border` / `crop_to_border_from_array` 加可选 `page_rect=None`
   - `split_border` / `split_border_from_array` 行为不变（仍各自跑 Hough）
   - `pipeline.run_pipeline` 在 `args.split == "border"` 时切换到 with_rects 路径
   - RTL 翻 `[sub_arrs, page_rects]` 同步

### 实测（ZHSY 5 页采样）

| 路径 | 用时 | 加速比 |
|---|---|---|
| split_border_from_array + crop_to_border ×2 (legacy) | 116ms | 1.00× |
| split_border_with_rects + crop(page_rect=) ×2 (A3) | 62ms | **1.86×** |

端到端 ZHSY 全本回归：
- 132 页输出 ✓（与 v1.5 baseline 完全一致）
- 66 outline 节点 ✓
- metadata 保留 ✓
- 单页输出尺寸差异 1-2px（Hough 检测方差，非 bug）
