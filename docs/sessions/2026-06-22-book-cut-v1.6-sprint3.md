## B3 Sauvola sqrt(var) 原地写（commit `e1f2929`）

**问题**：`binarize.sauvola_binarize_from_array` 算 std 时
```
mean_sq = mean ** 2          # float32 alloc #1
var = mean_sq - mean_sq      # float32 alloc #2
std = np.sqrt(var)           # float32 alloc #3
```
3 个临时 float32 数组 = 3 × H × W × 4B。4000² 输入 = **192 MB 临时**。

**修复**：让 3 个变换都**原地写**到 `mean_sq`（np.subtract / sqrt / maximum 都支持 `out=`）：

```python
np.subtract(mean_sq, mean * mean, out=mean_sq)  # var → mean_sq
np.maximum(mean_sq, 0.0, out=mean_sq)           # 截负
np.sqrt(mean_sq, out=mean_sq)                  # std → mean_sq
mean_sq /= R                                    # multiplier → mean_sq
mean_sq -= 1.0
mean_sq *= k
mean_sq += 1.0
threshold = mean * mean_sq
```

省 2 个 float32 临时（var + std 各 1），保留 1 个（mean_sq）作为工作缓冲。

**实测**（ZHSY 132 页，全流水线）：
- 时间：**1113ms → 920ms**（17% ↓）
- 内存（sauvola 阶段）：**256MB → 184MB**（28% ↓）

## E1-E3 GUI UX 改进（commit `d4430f2`）

### E1a：crop=none 时抗杂质禁用

抗杂质 checkbox（`--no-morph` 反义）在 `crop=none` 时无意义。
原代码不联动 → 用户可能勾了但 crop=none 时无效果，困惑。

**修复**：在 `run_gui()` 里加 trace：
```python
def _on_crop_change(*_a):
    morph_check.config(state="disabled" if crop_var.get() == "none" else "normal")
crop_var.trace_add("write", _on_crop_change)
```

### E1b：input 变化时 output 自动建议

`book-cut` 的 output 目录约定是 input 同级 + `_out` 后缀（CLI 习惯）。
GUI 里之前要手动填。

**修复**：input 变化 + output 为空 → 自动建议（用户已填不覆盖）：
```python
def _on_input_change(*_a):
    if output_var.get(): return  # 保护用户已填
    suggested = _suggest_output_dir(input_var.get())
    if suggested: output_var.set(suggested)
input_var.trace_add("write", _on_input_change)
```

`_suggest_output_dir` 是纯函数（无 Tk 依赖）→ 易测。

### E3：友好错误提示

原 `messagebox.showerror` 只显示 `❌ {e}`（原始 Python 异常字符串，非中文用户看不懂）。

**修复**：建 `_FRIENDLY_ERRORS` 映射表 + `_format_error(exc)`：
```python
_FRIENDLY_ERRORS = (
    (FileNotFoundError, "❌ 找不到文件，请检查输入路径是否正确"),
    (NotADirectoryError, "❌ 路径不是目录（输出目录必须是目录）"),
    (IsADirectoryError, "❌ 路径是目录而非文件"),
    (PermissionError, "❌ 没有访问权限，请检查文件/目录权限或是否被其他程序占用"),
)
```

原始 `type(exc).__name__: exc` 作为 hint 附后（用户可调试）。
