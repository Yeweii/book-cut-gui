# 2026-06-21 · book-cut v1.2 macOS GUI 打包

## 概要

把 v1.1 的 Tkinter GUI 打包成可在 macOS 双击运行的 `.app`，
让没有 Python 环境的同事也能用。

## 产物

- 路径：`dist/Book Cut.app`
- 大小：222 MB
- 架构：arm64（Apple Silicon）
- Bundle ID：`com.bookcut.app`
- 打包耗时：~30s（首次）；增量构建更快

## 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 打包工具 | PyInstaller | Tkinter 支持最成熟、`.app` 自动生成、零侵入 |
| 入口脚本 | `packaging/launch_gui.py` | 直接调 `run_gui()`，绕过 CLI argparse；双击即 GUI |
| 架构 | arm64 only | 当前 Mac 是 M 系列；Intel 端可重跑脚本（30s 一次） |
| 签名 | 无 | 个人用不需要 Apple Developer 账号；Gatekeeper 用右键"打开"绕过 |
| 公证 | 无 | 同上 |
| 体积优化 | 显式排除 matplotlib/PyQt/scipy | 不影响功能；能省 ~50MB（已用上大件） |

## 关键命令

```bash
bash packaging/build_macos.sh
```

脚本流程：
1. 准备 venv（不存在则创建）
2. `pip install -e ".[dev]"` + `pip install pyinstaller`
3. `rm -rf build dist` 清理
4. `pyinstaller packaging/Book Cut.spec`
5. 验证产物（路径 + 大小 + 架构）

## 已知限制

- **Gatekeeper 警告**：未签名应用首次打开需右键 → 打开。
  解决方案（分发时给用户的提示）：
  ```bash
  xattr -d com.apple.quarantine "/Applications/Book Cut.app"
  ```
- **arm64 only**：M1/M2/M3 直接装；Intel Mac 需在 Intel 上重打包。
- **大体积**：222MB（Python 解释器 ~50MB + opencv ~80MB + numpy ~30MB + pymupdf ~50MB + Tk ~20MB）。
  对比 Java 桌面 app 类似水平；不打算再优化。
- **samples 不打包**：32MB+ PDF 只对开发有用，不在 .app 里。

## 后续

- 若要分发给他人：考虑加自签名（`codesign --deep --sign -`）让 Gatekeeper 静默通过
- 若要上架：需 Apple Developer 账号 + notarize
- 缩减体积：可改 `--exclude-module matplotlib`（已加）+ `UPX` 压缩（PyInstaller 不太支持 macOS）
- Universal binary：`--target-architecture universal2` 但慢 2-3 倍
