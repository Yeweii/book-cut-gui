## 关键发现

### ✅ 文本页：质量优秀

任意抽 `_0030.png`、`_0050.png` 等页：

- 中缝定位精准（落在真装订线 ~col 1712）
- `border` 裁切干净，版框内裁切出有效区域
- Sauvola 二值化对泛黄纸基效果锐利、字迹清晰
- 无错切、漏切

### ⚠️ 封面/校色卡页：被强制对半切

`0001_茶山集八卷` 包含：

- 校色卡（左）、书名竖排（中）、纯黑背景
- 比例 3708×3862（接近正方形而非 2:1）
- 这是"单页 + 校色卡"，不是双页跨页

工具的 `find_gutter_column` 找不到真正的白色中缝，回退到中心 → 把书脊 + 校色卡都切成两半。

输出文件：
- `_0001.png` 校色卡 + 书脊左半
- `_0002.png` 书脊右半 + 校色卡右条
- 两者都是"半残品"

类似问题：`0065_茶山集八卷/pages/0065.jpg`（PDF 中 65 页）也是单页空白。

### 加了简单的单页检测

新模块 `book_cut/detect/single_page.py` + `split_gutter(..., auto_single_page=True)`。

**算法**：找到中缝候选后，比较两侧"墨迹"密度比（自适应阈值 = 中位数 - 30）。
- 较小一侧 / 较大一侧 < 0.1 → 视为单页，整图输出（counter += 1）

**新增测试**：
- `test_gutter_detects_single_page` —— 白底 + 单边墨迹 → 1 张
- `test_gutter_can_disable_single_page_detection` —— `--no-single-page` → 2 张
- `test_is_single_page_helper` —— 直接验证检测函数

**新增 CLI**：`--no-single-page` 关闭检测（默认开）

### 已知限制

1. **白底单页**：✅ 能识别（如纯白衬页）
2. **深底单页（封面）**：❌ 当前检测不到。原因：
   - 墨迹阈值 = `max(median - 30, 60)`
   - 封面整体偏暗（median ≈ 74），墨迹阈值 ≈ 60
   - 黑色背景（~50）也 < 60，被算成"墨迹"
   - 两边"墨迹"密度比 ~0.80，不触发单页条件
3. **真实中缝的检测**：`find_gutter_column` 的 `min_white_value=220` 在 300DPI 扫描上偏严，几乎所有页都回退到中心。但因为搜索范围 center ± 20%×width，落点还过得去，文本页质量不受影响。

## 推荐配方（v1.1）

```bash
# 默认配方（已校准）
python -m book_cut -i book.pdf -o out \
  --split gutter --crop border --binarize sauvola --pdf
```

古籍：必加 `--binarize sauvola` + `--crop border`。
倾斜严重：加 `--deskew`。
已知含封面/校色卡：建议用 `--no-single-page`（不触发可能误判），事后手动删除输出中最小几个文件。
