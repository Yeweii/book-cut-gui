## 概要

## 启动动机

用户想把扫描的 PDF/图片古籍按"中线/版框/对半"切分成单页，可选二值化、白边/版框内裁、倾斜校正、合并 PDF；提供 CLI + GUI 两种使用方式。

## 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 切分策略 | 三种全支持（gutter/border/half）+ CLI 切换 | 用户偏好"哪种效果好用哪种" |
| 中缝检测算法 | 列投影找"最长连续亮列" | 排除散点白边干扰 |
| 二值化默认 | Sauvola | 最适合古籍泛黄/不均光照 |
| 倾斜检测 | Hough 直线角度中位数（auto 回退投影法） | Hough 快且准；投影法无版框时能用 |
| 裁切找不到版框 | 回退 trim | 鲁棒性优先 |
| 流水线顺序 | load → deskew → split → crop → binarize → export | deskew 在 split 前（先正过来再切） |
| GUI | Tkinter 单窗口 + 后台线程 + queue | 简单、跨平台、Python 内置 |
| PDF 依赖 | pymupdf（输入）+ img2pdf（输出） | 无 poppler 二进制依赖；输出无损 |
| Python 版本 | 3.11.15 | 用户指定；后续考虑 Win 兼容 |

## 踩过的坑（已固化，下次别再踩）

1. **trim 阈值**——起初用"白像素 ≥ 95%"判定"有内容"行/列，稀疏内容列（如 12/300 像素黑）会被绕过。改用"任一非白像素"才稳。
2. **deskew 旋转方向**——detected 角度直接喂给 PIL.rotate，**不要再取负**。Y-down 坐标下符号巧合地一致。
3. **deskew 测试断言**——不能用"输出尺寸接近原图"（`expand=True` 会让尺寸叠加）。应改用"测量输出图线角度 < 0.5°"做断言。
4. **trim 测试断言**——`_page_with_white_margins` fixture 本身就有 80px 白边，trim 正确地切掉了 80+80=160px，输出 451 ≠ 600 是正确行为。测试应验算"输出尺寸 = 内容 + padding"，不是"输出 ≈ 输入"。
5. **pip 国内网络**——`pip install` 默认源在某些时段很慢，pymupdf 23MB 卡了 6 分钟无进展。改清华源（`https://pypi.tuna.tsinghua.edu.cn/simple`）秒装。

## 流水线

```
load → deskew (Hough/auto) → split (gutter/border/half)
  → crop (none/trim/border) → binarize (none/otsu/adaptive/sauvola)
  → export (PNG/JPG/TIFF/WebP + 可选 PDF)
```

## 推荐配方

```bash
# 版面整齐的现代古籍扫描
python -m book_cut -i book.pdf -o out --split gutter --crop trim --binarize sauvola --pdf

# 扫描有轻微倾斜 + 有版框
python -m book_cut -i book.pdf -o out --deskew --split border --crop border --binarize sauvola --pdf

# 漫漶 / 无版框古籍
python -m book_cut -i book.pdf -o out --deskew --split gutter --binarize sauvola --pdf
```
