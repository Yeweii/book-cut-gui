## 范围

新增 **Dry-Run 预览模式** —— 调参时不再"盲跑 130 页 20 秒"。

```bash
python -m book_cut -i book.pdf -o ./out --dry-run --sample-n 3 \
    --split gutter --binarize sauvola --deskew
```

输出 `book-cut-preview-<ts>/`：
- `preview_p*_compare.png`：3 列（原图 | L | R）并排 + 红色虚线 split column
- `preview_summary.json`：split confidence / crop boxes / timings / 自动调参建议

## 关键设计

### 1. `_compute_page` 纯计算函数
- 把 deskew → split → crop → binarize 全流程 + metrics 构建抽出
- 不写盘、不依赖 closure（接受所有参数 via kwarg）
- 复用给正常模式 + dry-run 模式

### 2. `_save_subpages` 写盘函数（closure）
- 包含 v1.4 outline 映射 + v1.7 fit-to-target + 计数
- dry-run 模式**完全跳过**这步

### 3. split confidence 量化
- **gutter**: `min(连续白段宽度/50, 1.0) × (1 - 中心偏离度)`，偏离 > 20% → 0
- **border**: Hough 找到的子图尺寸合理性
- **half**: 1.0（无检测）
- 在 summary.suggestion 给出调参建议

### 4. 写盘隔离
- `--dry-run` 模式下**不创建** `output` 目录（避免污染用户 FS）
- `--pdf` / `--format` / `--pdf-page-size` / `--no-outline` 写盘 flag 全部 warn 后忽略
