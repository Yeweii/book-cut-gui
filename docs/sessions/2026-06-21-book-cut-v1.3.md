# 2026-06-21 · book-cut v1.3 自适应裁切

## 概要

v1.1/v1.2 的 `--crop trim` 用硬编码 `threshold=240, padding=10`，
对**古籍泛黄/泛灰纸张**（paper median 200-220）会出现"黄边被当内容留下"问题。
v1.3 把这条路径改成**书级 paper color 学习 + 自适应阈值**，
默认 `auto`，CLI 暴露 `--crop-adaptive {auto,fixed}` 切回 v1.1 行为。

## 选型理由

| 子项 | 选 | 拒 |
|------|------|------|
| 单页 paper color | 95th percentile（clip [180,255]） | median 抗不了 50% 浓墨（cover median=136） / Otsu 给的是阈值不是 paper color |
| 书级聚合 | median of N=5 | mean 会被 cover 拉低；trimmed-mean 更复杂但收益低 |
| API 形式 | `CropConfig` dataclass，frozen | 4 个相关参数用 dataclass 避免签名腐烂 |
| Padding | max(min_dim*0.02, 5)，clamp 30 | 700-4000px 古籍都合理；小图不卡死、大图不爆 |
| 边缘"有内容" | sum>=3 ink 像素 | .any() 让 1px 噪声触发；.sum()>=5 太严、杀批注 |
| Border Canny/Hough | 保持静态 | 几何检测不受 paper color 影响；改 Hough 风险大 |
| CLI | --crop-adaptive + --paper-pages | 一个旋钮 + 一个高级旋钮，不爆炸 |
| GUI | checkbox + spinner | 镜像 CLI，spinner off 时 disabled |

## 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 估计器 | 95th percentile | 抗浓墨（ZHSY cover p95=255 而 median=136） |
| 聚合 | median of N=5 | 一页异常（cover）不拉低书级 |
| Backward compat | `config=None` 走原 v1.1 路径 | 4 个老 detect test 零修改 |
| 边界裁切 Canny/Hough | 保持静态 | 几何检测与纸色无关；trim fallback 透传 config 即可 |
| 暴露面 | `--crop-adaptive` 一刀 + `--paper-pages` 高级 | 不爆炸；用户不需理解 4 个正交参数 |
| GUI | checkbox + spinner | 镜像 CLI，spinner 在 off 时 disabled 防误调 |

## 已知限制

1. **白色扫描台**：与衬纸 mean 都 ≥ 240，book paper color 会偏高。**不影响 trim**（trim 是按 paper-30 判 ink，偏高只是更激进切一点）。
2. **N=5 极端情况**：若书前 5 页全是 cover/插页，book paper color 可能偏低（median 兜底到 50%），影响后续页 trim。可加 `--paper-pages 10` 缓解。
3. **未做 per-page override**：理论上应该"某页 paper 颜色偏差 >30 就用 per-page 估计"，但实测 ZHSY std=0 没必要，v1.4+ 再加。
4. **古籍天/地/内/外 方向 padding**：v1.3 不做（需先识别哪边是中缝）。v2 候选。

## 后续

- v1.4 候选：
  - per-page paper color override（检测某页 paper 偏离书级 >30）
  - Canny 自适应（`low = paper*0.4, high = paper*0.8`）—— v1.3 不做是因为 v1.1 Hough 在 ZHSY 跑得稳
- v2 候选：方向 padding（天/地/内/外）
