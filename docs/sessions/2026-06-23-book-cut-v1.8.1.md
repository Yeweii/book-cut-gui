## 关键设计

### 1. 边界检查（非抢占式）
- 单页 `_compute_page` 是原子的（不改）
- 主循环每页迭代前检查 `cancel_event.is_set()` → break
- 取消时已写出的 PNG 保留，PDF 不写

### 2. GUI 线程模型
- `on_run()` 新建 `threading.Event()` → 存到 `cancel_event_holder[0]`
- `_run_pipeline_thread(cancel_event=...)` 透传给 `run_pipeline`
- `on_stop()` 仅 set event + log "⏹ 正在停止..."（不杀线程）
- `poll_queue` 在 done/error 时 disable stop_btn

### 3. dry-run cancel
- `run_dry_run` 也支持 `cancel_event`
- 采样循环提前 break → 仍写出已采样的 preview + summary（取消 ≠ 失败）
