## 已知遗留（不在本次范围）

- **codesign / notarize**：未做（需 Apple Developer 账号 + 证书）。Gatekeeper 拦截需用户手动 bypass：
  - 右键 → 打开
  - 或 `xattr -d com.apple.quarantine "dist/Book Cut.app"`
- **跨架构**：默认仅 arm64（Apple Silicon）。Intel Mac 需在 Intel 上重跑 `bash packaging/build_macos.sh`
- **PyPI publish**：未做（需 twine + PyPI 账号 + 用户明确放行）。本地 wheel + sdist 已就绪可直接 `twine upload dist/book_cut-0.1.6*`
