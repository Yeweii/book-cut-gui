# 2026-06-23 · book-cut v1.9 图片预处理增强

## 概要

古籍扫描件常因保存条件差、扫描参数不一出现**墨迹模糊 / 纸张污渍 / 光照不均 / 整体偏暗**。
v1.9 在 deskew 之前新增 4 个独立的可选信号级增强 op：**锐化 / 降噪 / CLAHE 对比度 / 伽马校正**。
每个 op 支持 **fast / balanced / best** 三档后端（环境变量 `BOOKCUT_PREPROCESS_QUALITY` 覆盖默认）。

流水线新顺序：`load → preprocess → deskew → split → crop → binarize → export`。
preprocess 在 PIL.Image 上做，**不破坏 v1.5+ A1 单次 RGB→L 路径**。

## 选型理由

| 子项 | 选 | 拒 |
|------|------|------|
| 插入位置 | **deskew 之前** | 之后丢失"改善 deskew 精度"机会；crop 之后需 v1.5 paper override 联动 |
| 算法选型 | fast=PIL 内置 / balanced=双边滤波 / best=NL-Means | 全部用 NL-Means 太重（800ms/4000²）；全部 PIL 又无对比度增强 |
| 默认档 | **balanced** | fast 缺 CLAHE 无意义；best 慢 5x |
| CLI 入口 | 链语法 `--preprocess "a,b,c=v"` | 4 个 boolean flag 太粗；preset 单选无灵活性 |
| GUI 入口 | preset combobox + quality combobox + custom entry | 仅 combobox 无调参；text 输入框用户易错 |
| dry-run 集成 | 自动出 4 联对比图 | 仅 metrics 不直观 |
| 环境变量 | `BOOKCUT_PREPROCESS_QUALITY` | 与 `BOOKCUT_BINARIZE` 同一风格 |

## 性能实测（4000×4000 灰度，全 4 op 链）

| 档位 | 耗时 | 算法核心 |
|------|------|----------|
| `fast` | ~110ms | PIL ImageFilter |
| `balanced` | ~180ms | cv2 bilateralFilter（边缘保留 + 快） |
| `best` | ~850ms | cv2 fastNlMeansDenoising（NL-Means 全搜索） |

**踩坑**：原方案 balanced 直接用 NL-Means，实测 800ms/4000² 远超预期。换成 bilateralFilter 降到 180ms，质量略低但古籍去噪够用。

## 设计细节

### preprocess dispatcher（`preprocess/__init__.py`）

```python
def preprocess(image, chain, quality="balanced"):
    """链式应用 op；token 支持 `name` 或 `name=value` 覆盖默认。"""
```

支持的 op + 别名：
- `sharpen` / `sharp` —— amount 默认 balanced=1.5
- `denoise` / `dn` —— h 默认 balanced=7（bilateral σ）/ best=10（NL-Means）
- `clahe` / `cl` —— clip 默认 balanced=2.0
- `gamma` / `gm` —— value 默认 balanced=1.2

### 流水线集成

`_compute_page` 改：
```python
image = page.image
raw_original = image  # v1.9+：dry-run 用作"ORIGINAL"列对比

# 0. preprocess (v1.9+): deskew 之前，原始 PIL 上做
if preprocess_chain:
    image = _preprocess_op(image, preprocess_chain, quality=preprocess_quality)
# 1. deskew (unchanged)
```

返回 dict 加 `raw_original` 字段，让 dry-run 区分。

### dry-run 4 联图

`render_compare` 加 `preprocessed` 参数：
- `preprocessed is None` → v1.8 行为（3 列：原图 | L | R）
- `preprocessed is not None` → 4 列（原始 | preprocess | L | R）

## 测试（27 个）

- 4 op 各 3 档位产出（mode / dtype / 形状 / 数值差异）

- 流水线集成：`_compute_page` metrics 包含 preprocess

## 已知限制

1. **preprocess 总是 L 模式**：所有 op 内部 `convert("L")`，彩色古籍丢失颜色信息（古籍多为黑白，影响小）
2. **gamma 边界 clamp [0.25, 4.0]**：极端值抛 ValueError（防全黑/全白）
3. **NL-Means (best) 慢**：4000² ~850ms，100 页古籍额外 +85s
4. **A1 单次 RGB→L 仍生效**：preprocess 在 PIL 上做，不进 arr 路径

## v2.0 候选

- per-page preprocess override（与 v1.5 paper deviation 同思路）
- `--preprocess-after-crop`（binarize 之前的 per-page 增强）
- 自适应 preprocess（自动判断页面需要哪种增强）
- 彩色模式支持（gamma 可在 RGB 上做；CLAHE 在 LAB 空间做）
