## v1.3 vs v1.2 打包差异

v1.3 打包本质上 = v1.2 流程 + 两处小改：

1. **新增模块 `book_cut.detect.paper` 必须进 hiddenimports**
   - PyInstaller 的静态分析不一定扫到所有 import 路径
   - v1.3 的 `pipeline._build_crop_config` 动态引入 `from book_cut.detect.paper import ...`
   - 不加 → `.app` 启动后跑 crop 会 `ModuleNotFoundError: book_cut.detect.paper`

2. **版本号 0.1.2 → 0.1.3**
   - `CFBundleShortVersionString` + `CFBundleVersion`
   - 让用户 Finder 里看到 "Book Cut 0.1.3" 而不是 "0.1.2"

## 遇到的问题 & 解决

### `rm: dist: Directory not empty`

`dist/` 里只有上一次的 `.DS_Store`（Finder 留下的索引文件）。
`rm -rf` 在某些 macOS 状态下报这条迷惑错误。

**解决**：`rm -rfv dist build` 加 `-v` 看进度，必要时 `xattr -cr` 清扩展属性。
`build_macos.sh` 没 `-v` 是它的盲点，已在 `docs/packaging.md` 的"常见问题"中标注。

### PYZ 内容核查

PyInstaller 6 默认 `noarchive=False`——PYZ 归档嵌进 EXE 而不是单独 `.pyz` 文件。
结果：找不到 `PYZ-00.pyz` 在 Resources 顶层。

**解决**：PYZ 临时文件留在 `build/<name>/PYZ-00.pyz`，用 `pyi-archive_viewer` 打开。
命令已写进 `docs/packaging.md` 验证清单第 5 步。

### 启动闪退诊断

只 `pgrep` 看 PID 还在不够；要确认 Tkinter 框架 + book_cut 子模块都能 import。
本次 smoke test 用 `pgrep + ps` 验证了基础存活；后续若怀疑模块缺失，
用 `lsof -p <pid>` 看 `_tkinter.cpython-311-darwin.so` 是否加载、
用 Console.app 看崩溃报告。

## 已知限制

1. **未签名**：双击会被 Gatekeeper 拦，提示"无法打开因为来自身份不明开发者"。
   绕过：`xattr -d com.apple.quarantine "dist/Book Cut.app"` 或右键打开。
   正式分发需 Apple Developer 账号 + `codesign` + `notarytool`。
2. **arm64 only**：当前 Mac 是 M 系列，Intel 端需重跑。
   Universal binary 流程已写进 `docs/packaging.md`，但本次未实际生成。
3. **体积 222MB**：opencv-python ~80MB + pymupdf ~50MB + Python ~50MB 是大头。
   spec 已 exclude matplotlib/PyQt/scipy/wx，进一步优化空间小。
4. **`dist/` 不进 git**（`.gitignore` 里有），每次重打都从零开始。
   优点：仓库轻；缺点：CI 必须重跑全流程。
