# 2026-06-23 · book-cut v1.8 Dry-Run 预览模式（提案）

> 状态：提案，待拍板
> 续 `2026-06-22-v1.7-pdf-page-size.md`

## 1. 目标

**不写实际输出**，仅跑前 N 页（默认 3）全流水线 → 输出对比图 + 指标 JSON，方便调参时快速验证
`--split` / `--crop` / `--binarize` / `--deskew` 组合效果，而不是"盲跑 130 页 20 秒后发现 split 点偏了"。

需求场景：
- 选 split 策略：在 gutter / border / half 之间犹豫
- 调 crop 自适应：纸张色阈值 / padding 是否合理
- 调 deskew：Hough vs 投影是否成功识别倾斜角
- 调 binarize：sauvola window/k 参数对泛黄纸效果

**核心交付**：
1. 一张拼图（per 采样页）= 原始图 | 切分左页 | 切分右页（并排或竖排 + 标注 split 列位置）
2. 一个 JSON = 每页指标 + 汇总 + 推荐下一轮调参提示

## 2. 现状

`pipeline/orchestrator.py:run_pipeline()` 是**全量不可中断**：

```python
for page in iter_pages(source):
    out_left, out_right = _process_one(page, ...)
    save_image(out_left, ...)
    save_image(out_right, ...)
# 跑完才知 split 偏没偏、crop 紧没紧
```

调参唯一的"快速反馈"路径：缩小样本（手抄前 3 张 → 文件夹），代价是失去原 PDF outline / 真实上下文。

## 3. 候选方案

| 方案 | 思路 | 改动量 | 评估 |
|------|------|--------|------|
| A. 流水线 dry-run 模式 | 加 `--dry-run` flag：跳过 `save_image` + `save_pdf`，仅采样前 N 页 | 小 | **采用** |
| B. 独立 `--preview` 子命令 | 完全独立的 preview 入口，复用各 step 函数 | 中 | 不必（CLI/GUI 多一个入口，维护成本高） |
| C. 跑全量 + 中途按 Ctrl-C | 加 SIGINT 优雅退出 | 中 | 体验差（已经耗 CPU） |

**A 方案核心**：`--dry-run` 走 `run_pipeline(dry_run=True, sample_n=N)` → 仅跑前 N 页 + 不写盘 + 收指标 + 出预览图。

## 4. CLI 设计

```bash
# 启用 dry-run + 默认采样 3 页 + 输出到默认 tmp 目录
python -m book_cut -i book.pdf -o ./out --split gutter --binarize sauvola --dry-run

# 显式指定采样数 + 预览输出位置
python -m book_cut -i book.pdf -o ./out --dry-run --sample-n 5 --preview-output ./preview

# 与现有调参 flag 全兼容
python -m book_cut -i book.pdf -o ./out --dry-run --sample-n 3 \
    --deskew --split border --crop border --binarize sauvola

# dry-run 模式下 --pdf / --format / --pdf-page-size 等写盘相关 flag 全部 warn 后忽略
```

| 新增 flag | 默认 | 说明 |
|-----------|------|------|
| `--dry-run` | 关 | 启用预览模式；不写真图/PDF |
| `--sample-n N` | 3 | 采样页数（输入 PDF = 前 N 页；文件夹 = 前 N 文件；单图 = N=1 自动） |
| `--preview-output DIR` | 系统 tmpdir `book-cut-preview-<ts>` | 预览图 + JSON 落盘位置 |

**作用域规则**：
- `--dry-run` 开启 → `--pdf` / `--format` / `--pdf-page-size` / `--no-outline` 等**写盘 flag** 全部 warn 后忽略
- GUI 路径：勾选 "Dry-run" → 整张"输出格式"行 disable + N spinner enable + "打开预览目录" 按钮 enable
- 退出码：0 = 成功 / 1 = 输入错（与 v0.1.6 一致）

### 5.2 对比拼图布局

每页 1 张 PNG，**横向并排 3 列**（原图 / L / R）：

```
┌────────────────┬──────────────┬──────────────┐
│  ORIGINAL      │  PAGE L      │  PAGE R      │
│                │              │              │
│  [deskew 后]   │  [split L]   │  [split R]   │
│                │              │              │
│  split line ┊  │              │              │
│              x_split         │              │
│                │              │              │
└────────────────┴──────────────┴──────────────┘
   标题 + 尺寸     标题 + 尺寸    标题 + 尺寸
   ink/size       crop 范围      crop 范围
```

实现要点：
- 三张图**等高对齐**（取 max(高) 缩放，等比）
- 标题区 60px：源文件名 + 页号 + 实际像素尺寸
- 原图上**画一条红色虚线**标记 split column（x_split）—— 调参时一眼看出 gutter 选得对不对
- 单页（无 split）情况：仅 2 列（原图 | 处理后），split line 段标 "single-page mode"
- 总宽限制 ≤ 6000px（防 4K PDF 拼接爆内存）；超宽 → 三列各自缩到 2000px
- 底部统一画**白色 padding**（与 v1.7 留白策略一致）

### 6.3 split confidence（新指标）

把现有 gutter/border 的"找到的质量"量化为 0-1：

- **gutter**: `confidence = min(连续白段宽度 / 50, 1.0) × (1 - 中心偏离度)` —— 中心偏离 > 20% 视为低 confidence
- **border**: `confidence = Hough 直线对数 / 期望数 × 平均直线长度比`
- **half**: `confidence = 1.0`（无检测，固定）

`summary.suggestion` 根据 confidence 给出建议（如 "page 2 confidence 0.42 偏低，建议 --split border"）—— 后续 v1.9 候选。
