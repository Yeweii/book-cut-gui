# 2026-06-22 · book-cut v1.7 PDF 页面统一尺寸（提案）

> 状态：提案，待拍板
> 续 `2026-06-22-book-cut-v0.1.7-fix.md`

## 1. 目标

古籍扫描件合并 PDF 时，**所有页 page size 一致**：要么按标准预设（A4 / A5 / Letter / Legal），
要么按用户自定义 WxH（mm / cm / inch / px），要么按输入自动（首页 / 全书 max）。

需求背景：当前 `img2pdf.convert([paths])` 直接用各图原分辨率作 page size，结果同本书内
封面 3708×3862、文本 3424×3330、插图页 4288×3330 —— 在 PDF 阅读器里每页大小都不同，
缩放阅读体验差。`--pdf-page-size` 选项解决此问题。

## 2. 现状

`src/book_cut/io/exporter.py:64-74` `save_pdf`：
```python
def save_pdf(image_paths: list[Path], pdf_path: Path) -> Path:
    import img2pdf
    pdf_path.parent.mkdir(parents=True, exist_ok=True)
    with open(pdf_path, "wb") as f:
        f.write(img2pdf.convert([str(p) for p in image_paths]))
    return pdf_path
```

`img2pdf.convert` 逐图取原分辨率作 page size，无统一化能力。
要改只能在调用 `save_pdf` 之前**先把每张图 resize/fit 到统一尺寸**，或者改用 `img2pdf` 的
`layout_fun` 参数指定每页尺寸 + 图片 fit 策略。

## 3. 候选方案（已比较）

| 方案 | 思路 | 改动量 | 评估 |
|------|------|--------|------|
| A. 提前 fit-to-target | 流水线末尾把每张子图等比 fit + 留白 paste 到 (W,H) 画布 | 小 | 采用 |
| B. img2pdf layout_fun | 用 `layout_fun` 在 PDF 写出时统一每页尺寸 | 中 | 不必（A 已解决问题） |
| C. reportlab 重写 | reportlab 生成统一尺寸 PDF | 大 | 破坏现有 img2pdf 链路 + outline 注入 |

**A 方案核心**：在 `_process_one` 末尾（`save_image` 前）加 fit-to-target 步骤，
后续链路（save_image + save_pdf + inject_outline_and_metadata）零修改。

## 4. CLI 设计

```bash
# 默认：保持现行为（不统一）
--pdf-page-size keep

# 自动取 max(W)×max(H)：预扫所有输入页
--pdf-page-size max

# 用首页尺寸
--pdf-page-size first

# 标准预设（mm）
--pdf-page-size a4        # 210×297
--pdf-page-size a5        # 148×210
--pdf-page-size letter    # 8.5×11 inch
--pdf-page-size legal     # 8.5×14 inch

# 自定义（配 --pdf-page-dim + --pdf-page-unit）
--pdf-page-size custom --pdf-page-dim 280x200 --pdf-page-unit mm
```

预设表（统一 mm 存储，转换在内部完成）：
| token | 宽×高 |
|---|---|
| a4 | 210×297 mm |
| a5 | 148×210 mm |
| letter | 215.9×279.4 mm (8.5×11 in) |
| legal | 215.9×355.6 mm (8.5×14 in) |

`--pdf-page-unit` 仅 custom 时有效：`mm`（默认）/ `cm` / `inch` / `px`。
px 转换约定：96 DPI（即 1 inch = 96 px = 25.4 mm）— 与 img2pdf 默认一致。

**作用域**：仅 `--pdf` 模式生效；非 PDF 模式 warn 后忽略（图片输出保持原分辨率）。

## 6. 图片 fit 策略

输入:产物子图 `(w, h)`,target `(W, H)`（L 模式，灰度）

```python
def fit_to_canvas(img: Image.Image, target_w: int, target_h: int,
                  bg: int = 255) -> Image.Image:
    """等比 fit + 居中 paste。留白填 bg（默认白）。"""
    w, h = img.size
    scale = min(target_w / w, target_h / h)
    new_w = max(1, int(w * scale))
    new_h = max(1, int(h * scale))
    fitted = img.resize((new_w, new_h), Image.Resampling.LANCZOS)
    canvas = Image.new(img.mode, (target_w, target_h), bg)
    canvas.paste(fitted, ((target_w - new_w) // 2, (target_h - new_h) // 2))
    return canvas
```

放在 `_process_one` 末尾、`save_image` 前。若 `--pdf-page-size keep` 则跳过。
画布 mode 跟随子图（L / RGB），bg 默认 255（白）；binarize 后的 L 子图填 255 即可。
