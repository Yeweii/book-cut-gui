# 2026-06-21 · v1.5 per-page paper color override（提案）

> 状态：提案，未实现
> 分支：`v1.5-per-page-paper`（待创建）
> 拍板时间：2026-06-21
> 关联：v1.3 session note "已知限制 #3" + 2026-06-21 optimization backlog

## 1. 目标

古籍书内常混合多种纸张（扉页白、目录薄黄、正文深黄、插图页厚白、护封色卡等）。
v1.3 用"前 5 页 median 估书级 paper color"对 ZHSY（std=0）有效，但**书级偏离大的书会出问题**：

- 前 5 页偏白 → 书级估 250 → 正文黄页（p95=190）用 250-30=220 作 ink_thr → 黄纸被误判墨迹，留下黄边
- 前 5 页偏黄 → 书级估 200 → 插图白页（p95=255）用 200-30=170 作 ink_thr → 文字切过头，裁掉边缘

v1.5 加 **per-page paper color override**：某页 p95 偏离书级 > threshold 时，单页改用 per-page 估计。

## 2. 选型理由

| 候选 | 评估 | 选/拒 |
|------|------|------|
| **A. 偏离阈值触发 override** | 简单、易理解、性能开销小（每页 +5ms estimate） | **选** |
| B. 滑窗 median（5 页窗口扫全书） | 鲁棒但开销大（每页都估 + 维护 deque），且与"书级 paper"心智冲突 | 拒 |
| C. 固定 N 页重新估 book paper | 解决扉页问题但需要分段，复杂度高 | 拒 |
| D. 自适应 threshold（按 std 调整） | 治标不治本，std 小的书恰好不需要 override | 拒 |

**A 方案核心**：单页 `estimate_paper_color` + 偏离判断。threshold 默认 30（与 ink_offset 对齐）。

## 3. 现状与触发条件

### 现状（v1.3 + v1.4）

```python
# pipeline._build_crop_config
sampled = pages[:paper_pages_n]  # 前 5 页
colors = [estimate_paper_color(p.image) for p in sampled]
book_paper = aggregate_paper_color(colors)  # median
config = default_crop_config(paper_color=book_paper)
```

主循环里 `sub_pages = _crop_pages(sub_pages, crop_mode, config=crop_config)` —— **config 全书用同一个**。

### 触发场景

| 书 | 前 5 页 p95 | 正文 p95 | 书级估 | 正文用书级 trim_thr | 正文期望 trim_thr | 偏差 |
|---|---|---|---|---|---|---|
| ZHSY（均匀） | 218 | 218 | 218 | 188 | 188 | 0 ✓ |
| 扉页偏白 + 正文黄 | 250 | 190 | 220 | 190 | 160 | 30（黄边） |
| 扉页偏黄 + 正文白 | 190 | 250 | 220 | 190 | 220 | 30（切过头） |
| 插图页白 + 正文黄 | 250 | 200 | 250 | 220 | 170 | 50（黄边严重） |

threshold=30 触发：偏离 ≥ 30 即 override。

## 4. 数据流

```
1. 采样阶段（同 v1.3）：
   sampled = pages[:paper_pages_n]
   colors = [estimate_paper_color(p) for p in sampled]
   book_paper = median(colors)        # 全局 paper color

2. 主循环（每页）：
   sub_pages = _split(image, ...)     # 已切分
   sub_pages = _apply_page_order(sub_pages)

   for sub in sub_pages:              # 1:1 或 1:2
       per_paper = estimate_paper_color(sub)        # 5ms/页
       if abs(per_paper - book_paper) > deviation:  # 默认 30
           page_config = default_crop_config(paper_color=per_paper)
       else:
           page_config = crop_config  # = book-level

       sub = crop(sub, mode, config=page_config)
       ...
```

## 5. 关键设计

### 5.1 override 仅影响 ink_thr，padding 不变

- 视觉一致性：书内 padding 应统一（不然看起来边框忽大忽小）
- 切换 ink_thr 而不切 padding：避免突兀
- 涉及：`CropConfig.ink_threshold`（paper-30）；`padding` 保持书级 `adaptive_padding(h, w)`

### 5.2 threshold 默认 30

与 `ink_offset=30` 对齐：

```
if abs(per - book) > 30:
    ink_thr 切换 = per - 30
else:
    ink_thr = book - 30
```

| 偏离 | 行为 | 理由 |
|---|---|---|
| < 30 | 用 book | 安全区（v1.3 等价行为） |
| ≥ 30 | 用 per | 确实有差异 |
| = 999 | 全 per-page（CLI `--paper-deviation 999`） | 极端调试 |

CLI `--paper-deviation` 默认 30，`--paper-deviation 0` = 强制 per-page（等同"全 per"）。

### 5.3 与 A1 backlog 联动

A1 把 RGB→L 单次化后，pipeline 主循环可拿到灰度数组。
per-page `estimate_paper_color` 可直接消费灰度数组（不重新 convert）：

```python
# A1 后
arr_gray = np.asarray(img.convert("L"))
for sub in sub_pages:
    per_paper = estimate_paper_color_from_array(arr_gray[sub_box])  # 0 额外开销
    ...
```

**好处**：per-page override 几乎是"白嫖"，0 性能损失。
**现状（A1 未做）**：override 自己 convert("L")，每页 +5ms × 500 页 = 2.5s 额外开销。

**实施顺序建议**：A1 必须先于 per-page override 完成（否则性能不达标）。

### 5.4 per-page 估计稳定性

单页 `estimate_paper_color` 用 95th percentile + clip [180, 255]，已很稳：
- 抗 50% 浓墨（p95 仍返 255）
- clip 防异常值
- 单页用 median 不可能（页内只有 1 个值）

**风险**：极少数页（页内 100% 墨迹、纯黑白对比）可能估错。threshold=30 留安全边。

### 5.5 override 不影响 crop mode

`--crop border` 模式下，border 检测失败 fallback 到 trim 时也用 per-page config（与 v1.3 fallback 透传 config 一致）。

## 9. 风险与缓解

| 风险 | 缓解 | 严重度 |
|------|------|--------|
| A1 未做，per-page 自己转灰度 → +2.5s/500 页 | **实施顺序强制 A1 先做**；若 A1 推迟，per-page 可选"per N 页估一次" | 中 |
| per-page 估错（页内 100% 墨迹）| threshold 30 留安全边；极端情况选 book_paper | 低 |
| per-page override 频繁触发（书内混纸严重）| 用户可调 `--paper-deviation 50` 拉高阈值 | 低 |
| override 改变 padding 行为导致视觉不一致 | 设计 §5.1 明确 padding 不变 | 低 |
| 与 v1.3 backward compat 破坏 | 默认 deviation=30，ZHSY std=0 行为完全一致 | 低 |

## 10. 已知限制

1. **per-page estimate 单点**：没有"页内多区域 estimate 取 median"——单页 1 次 estimate
   - 实际古籍页内 paper 均匀，1 次够用
2. **override 不传递到 N=1 采样页**：前 paper_pages_n=5 页是"已知"书级代表，不走 override
   - 否则 override 自我引用（per-page 影响自己）
3. **override 不影响下一本书**：每本书独立估 book_paper（pipeline 现状）
