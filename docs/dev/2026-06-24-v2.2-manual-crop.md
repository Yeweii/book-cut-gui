# v2.2 提案：手动裁切工具（manual crop + GUI 拖框 + preset）

> 状态：🚧 提案阶段（基于分支 `v2.1-trim-ab`）
> 日期：2026-06-24
> 关联：`docs/dev/2026-06-24-v2.1-trim-ab.md`（auto-trim 增强实验，互补关系）

## 1. 背景与问题

### 1.1 用户反馈

> "由于裁剪效果不好，能否给出裁剪工具，手动进行偶数页与奇数页的裁剪，可应用于全部奇/偶数页。"

> "做拖框功能。放在独立版本 v2.2。split=none 也可以这么做。"

### 1.2 auto-trim 当前局限

| 问题 | 根因 | 尸子图实测 |
|------|------|-----------|
| 版框线被当墨迹内容 | bbox 用 `< ink_thr` 全局单阈值，版框线 = ink | 左边白边永远裁不掉 |
| safety margin 把贴边真内容也保护 | safety 命中 → 整图保留 | 4917×7610 (裁掉 31.1%) 仍 91.6% 白边 |
| 难以适应所有古籍版式 | 鱼尾/版心/批注横线 等特殊结构 | 各家书差异大 |
| paper color 估计误差 | 灰阈值对泛黄/暗角鲁棒性差 | 已用 v2.1 A+B 改善但仍有边 |

### 1.3 关键观察

古籍双页扫描天然有**奇偶页镜像结构**：
- Odd 页 = 右半页（中缝在**左**侧）
- Even 页 = 左半页（中缝在**右**侧）
- 物理上互为镜像 → **一份 crop 可复用为镜像**

**结论**：用户提供 4 个 padding（top/bottom/inner/outer）+ mirror_even 标志，即可覆盖古籍双页裁切需求。

### 1.4 与 v2.1 trim-ab 的关系

| 维度 | v2.1 trim-ab | v2.2 manual crop |
|------|--------------|------------------|
| 自动化程度 | 全自动（算法增强） | 全手动（用户介入） |
| 适用场景 | 大多数书 | auto 失败的疑难书 |
| 改动量 | 中（CCA + binarize） | 中大（GUI 拖框） |
| 关系 | **互补** | **互补** |
| 是否替代 | 不 | 不 |

**v2.2 是 auto 之外的兜底通道**，不是替代品。

## 2. 目标

提供**手动裁切工具**作为 auto 的兜底：

1. 用户能**精确指定 4 个 padding**（top/bottom/inner/outer）
2. 偶页**自动镜像**（inner↔outer 互换），无需单独设置
3. 支持 **JSON preset** 持久化与跨书复用
4. 提供 **GUI 拖框**（v2.2 主线，不是 v2.3 推迟）
5. 与 **split=none** 兼容（单页输入也走同一套）
6. 与 auto **完全替代**关系（manual 接管时不跑 auto）

## 4. 方案

### 4.1 数据模型

```python
# src/book_cut/detect/manual.py (新)

@dataclass(frozen=True)
class ManualCropProfile:
    """手动裁切 profile。
    
    Attributes:
        top: 顶部裁掉多少 px（从顶边向内数）
        bottom: 底部裁掉多少 px（从底边向内数）
        inner: 中缝侧裁掉多少 px（odd 页 = 左边）
        outer: 外侧裁掉多少 px（odd 页 = 右边）
        mirror_even: 偶页是否自动 inner↔outer 镜像
        source_size: 记录原图 (W, H)，跨书校验用
        notes: 用户注释
    """
    top: int
    bottom: int
    inner: int
    outer: int
    mirror_even: bool = True
    source_size: tuple[int, int] | None = None
    notes: str = ""
    
    def to_json(self) -> str:
        ...
    
    @classmethod
    def from_json(cls, s: str) -> "ManualCropProfile":
        ...
```

### 4.2 JSON preset 格式

```json
{
  "version": 1,
  "name": "尸子卷_浙江书局_光绪三年刊",
  "odd_page": {
    "top": 50,
    "bottom": 40,
    "inner": 80,
    "outer": 30
  },
  "mirror_even": true,
  "source_size": [4947, 7610],
  "notes": "左边版框线密集，inner 加大"

```

存放在 `samples/crop_profiles/<name>.json`。

### 4.3 apply_manual_crop 算法

```python
def apply_manual_crop(
    arr: np.ndarray,
    profile: ManualCropProfile,
    is_even: bool = False,
) -> np.ndarray:
    """按 profile 切出子图。
    
    Args:
        arr: 灰度 ndarray（已切分后的子图）
        profile: 手动裁切配置
        is_even: 是否偶页（影响 inner/outer 方向）
    
    Returns:
        裁切后的 ndarray
    
    Raises:
        ValueError: padding 越界（top+bottom >= H 或 inner+outer >= W）
    """
    h, w = arr.shape[:2]
    if profile.top + profile.bottom >= h:
        raise ValueError(
            f"top+bottom ({profile.top+profile.bottom}) >= height ({h})"
        )
    if profile.inner + profile.outer >= w:
        raise ValueError(
            f"inner+outer ({profile.inner+profile.outer}) >= width ({w})"
        )
    
    if is_even and profile.mirror_even:
        # 偶页：inner↔outer 镜像
        top, bottom = profile.top, profile.bottom
        left, right = profile.outer, w - profile.inner
    else:
        # 奇页（或不镜像）：正常
        top, bottom = profile.top, profile.bottom
        left, right = profile.inner, w - profile.outer
    
    return arr[top:h-bottom, left:right]
```

### 4.4 CLI 接口

```bash
# 方式 A：直接给 padding
book-cut input.pdf -o out/ --crop manual \
    --manual-odd-padding "T=50,B=40,I=80,O=30" \
    --manual-mirror-even

# 简写（顺序 T,B,I,O）
book-cut input.pdf -o out/ --crop manual \
    --manual-odd-padding "50,40,80,30"

# 方式 B：从 preset
book-cut input.pdf -o out/ --crop manual \
    --manual-preset samples/crop_profiles/尸子.json

# 方式 C：保存当前 manual 配置为 preset
book-cut input.pdf -o out/ --crop manual \
    --manual-odd-padding "50,40,80,30" \
    --manual-save-preset out/尸子.json
```

参数一览：

| 参数 | 默认 | 作用 |
|------|------|------|
| `--crop {auto,border,trim,manual}` | auto | 加 `manual` 选项 |
| `--manual-odd-padding "T,B,I,O"` 或 `"K=V,..."` | — | 4 个 padding |
| `--manual-mirror-even` | True | 偶页 inner↔outer 镜像 |
| `--manual-preset PATH` | — | 从 JSON 加载（覆盖 CLI） |
| `--manual-save-preset PATH` | — | 运行时保存为 JSON |

### 4.5 与 pipeline 集成

```
load → deskew → split → [crop] → binarize → export
                          ↓
              ┌────────────┴────────────┐
              ↓                         ↓
       crop_adaptive=auto        crop_adaptive=manual
       (现有 CropConfig 路径)     (新增 ManualCropProfile)
                                  → 完全替代 auto
```

**关键改动点**：
- `pipeline/crop_config.py::_build_crop_config` 加 `crop_adaptive=="manual"` 分支 → 返一个携带 `manual_profile` 的特殊对象
- `detect/trim.py::trim_margins` 加 `manual_profile=None` 参数；`is not None` 时走 manual 路径，skip 所有 auto 逻辑
- `detect/border.py::crop_to_border` 同理（border 模式下 manual 也支持）
- `pipeline/orchestrator.py::_crop_pages` 拿到 `is_even`（从 split 输出知道）传给 crop
- `ManualCropProfile` 走完整 pipeline（deskew 后才裁，与现有 crop 同位置）

### 4.6 奇偶页判断（orchestrator）

| split mode | odd/even 判定 |
|------------|---------------|
| `none` | 所有页当 odd 处理（无镜像必要） |
| `gutter` / `border` / `half` | split 输出 [left, right]，LTR：left=even, right=odd；RTL：反之 |
| 多页 PDF（split 后每页都切） | 每张子图独立判 odd/even（按 split 输出顺序） |

### 4.7 split=none 适配

- 跳过切分，整图 = 1 张
- "Mirror to even pages" checkbox：**hidden** 或 **disabled**（带 tooltip "split=none 无奇偶页"）
- Canvas 显示原图（缩放后）
- 拖框 → ManualCropProfile
- 全部页都应用同一 profile（每页当 odd 页处理）

### 5.2 拖拽交互规则

|----------|------|

### 5.3 视觉编码

- 顶/底边：红色（裁切线）
- 内/外边（中缝/装订侧）：蓝色
- 8 个 handle：小方块（4 角 + 4 边中点），8×8 px
- 框外区域：20% 透明黑遮罩（让保留区域更突出）
- 框内：原图，无遮罩
- 实时显示 padding 数值（hover 时浮窗）

### 5.4 坐标映射

```python
def canvas_to_image(cx, cy, scale):
    """Canvas 坐标 → 原图坐标。"""
    return int(cx / scale), int(cy / scale)

def padding_from_rect(rect_in_image, img_size, is_even, mirror_even):
    """矩形 → 4 个 padding。"""
    iw, ih = img_size
    L, T, R, B = rect_in_image
    top_pad = T
    bottom_pad = ih - B
    if is_even and mirror_even:
        # 偶页镜像
        inner_pad = iw - R
        outer_pad = L
    else:
        inner_pad = L
        outer_pad = iw - R
    return top_pad, bottom_pad, inner_pad, outer_pad
```
