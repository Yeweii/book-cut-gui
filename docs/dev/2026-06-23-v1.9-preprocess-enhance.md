# 2026-06-23 · book-cut v1.9 图片预处理增强（提案）

> 状态：提案，待拍板
> 续 `2026-06-23-v1.8-dry-run.md`

## 1. 目标

古籍扫描件常因保存条件差、扫描参数不一出现**墨迹模糊 / 纸张污渍 / 光照不均 / 整体偏暗**
等问题。当前流水线（deskew → split → crop → binarize → save）只能"几何 + 二值化"，
缺乏**信号级图像增强**。本提案加 4 个独立可选功能：

| 功能 | 算法 | 解决 |
|------|------|------|
| 锐化 | Unsharp Mask（cv2 / PIL.ImageFilter） | 笔画模糊、OCR 友好 |
| 降噪 | NL-Means / Bilateral（cv2.fastNlMeansDenoising） | 1-3 px 尘点、扫描噪点 |
| 对比度增强 | CLAHE（cv2.createCLAHE） | 泛黄纸、光照不均 |
| 伽马 / 亮度校正 | gamma 查找表 | 深底封面、过曝扫描 |

**核心交付**：
1. `preprocess/{sharpen,denoise,clahe,gamma}.py` 4 个新模块（**每个模块支持 fast/balanced/best 三档**）
2. `preprocess/__init__.py` 加 `preprocess(image, chain, quality)` dispatcher
3. CLI：`--preprocess` 链式语法 + `--preprocess-quality` 三档（与 binarize 同级）
4. GUI：combobox（preset）+ 质量 combobox + 自定义参数面板
5. 流水线插入点：**deskew 之前**（与 A1 单次 RGB→L 兼容）
6. dry-run 集成：新功能自动出 before/after 对比图

## 2. 现状

`src/book_cut/preprocess/` 当前只有 deskew / binarize 两个模块。
流水线主循环 `_compute_page`（`pipeline/orchestrator.py:183`）：

```python
image = page.image  # PIL.Image (RGB/RGBA/L)
# 1. deskew
if deskew_enabled:
    arr = deskew_from_array(np.asarray(image.convert("L")))
else:
    arr = np.asarray(image.convert("L"))
# 2. split → 3. crop → 4. binarize → save
```

**关键约束**（来自 memory & v1.5+ A1）：
- A1 已实现"单次 RGB→L"：主循环末尾输出 `arr: ndarray(float32)` 串到下游
- binarize 走 `_from_array` 私有变体（`preprocess/binarize.py:80`）—— 新模块必须支持 arr 路径
- 现有 binarize 不动

## 3. 候选方案（已比较）

### 3.1 流水线插入位置

| 位置 | 优势 | 劣势 | 评估 |
|------|------|------|------|
| A. **deskew 之前（原始 RGB）** | 降噪/对比度可同时改善 deskew 精度；A1 arr 路径不破坏 | 锐化在 RGB 上做，可能放大彩色噪点 | **采用** |
| B. deskew 之后、split 之前 | 几何校正后再锐化，split 更准 | deskew 仍吃原始噪声；A1 路径需重排 | 不采用 |
| C. crop 之后、binarize 之前 | 单页级别处理，最局部 | 不影响 split/crop 几何检测；但失去"改善 deskew"机会 | 备选（v2.0 per-page override） |
| D. 新增 `--postprocess` 在 save 前 | 不影响几何检测 | 完全失去改善 deskew 机会 | 不采用 |

**拍板**：位置 A。所有 4 个功能均在 deskew 之前、PIL.Image 上做。
后续 v2.0 可在 binarize 之前再加 per-page 增强（与 v1.5 per-page paper override 同思路）。

### 3.2 算法后端选择

每个 op 都有"快/平衡/最佳"三档实现：

| op | fast (PIL.ImageFilter) | balanced (cv2 默认) | best (cv2 高质量) |
|----|------------------------|---------------------|-------------------|
| sharpen | `ImageFilter.SHARPEN`（3×3 锐化核） | `cv2.GaussianBlur + addWeighted`（amount=1.5, radius=1.0） | 同 balanced + amount=2.0, radius=1.5 |
| denoise | `ImageFilter.GaussianBlur(radius=1)` | `cv2.fastNlMeansDenoising(h=7)` | 同 balanced + `cv2.fastNlMeansDenoising(h=10, templateWindowSize=7, searchWindowSize=21)` |
| clahe | N/A（PIL 无）| `cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))` | 同 balanced + `clipLimit=3.0, tileGridSize=(8,8)` |
| gamma | LUT 1.0 → 1.0（no-op） | numpy `np.power(arr/255, 1/γ) * 255`（γ=1.2） | 同 balanced + 允许任意 γ |

**原则**：
- `fast` 用 PIL 内置，**零额外依赖**（PIL 已在 requirements）
- `balanced` / `best` 用 cv2，**零额外依赖**（cv2 已在 requirements）
- 默认 `balanced`，对齐 binarize 的 `--binarize` 默认逻辑

### 3.3 入口形态

| 方案 | 思路 | 评估 |
|------|------|------|
| **A. CLI `--preprocess` 链 + GUI combobox**（推荐） | `--preprocess "sharpen,denoise,clahe"` + `--preprocess-quality balanced`；GUI 同级 combobox | 采用：链式语法表达力强、向后兼容（默认 `none` = 空链） |
| B. 4 个独立 boolean flag | `--sharpen --denoise --clahe --gamma` | 简单但粒度粗，无法调参、无法表达"先后顺序" |
| C. `--preprocess` 单 preset | `--preprocess {none,light,standard,strong}` | 用户无法选具体子集；preset 拍板成本高 |

## 4. CLI 设计

```bash
# 默认：不处理（保持 v1.8 行为）
python -m book_cut -i book.pdf -o ./out --split gutter --crop border --binarize sauvola

# 启用：预设链 + 默认 balanced
python -m book_cut ... --preprocess "sharpen,denoise,clahe"

# 改质量档：fast（只 PIL 内置，最快）
python -m book_cut ... --preprocess "sharpen,denoise,clahe" --preprocess-quality fast

# 改质量档：best（NL-Means h=10）
python -m book_cut ... --preprocess "denoise" --preprocess-quality best

# 伽马 + 锐化（古籍深底封面场景）
python -m book_cut ... --preprocess "gamma,sharpen"
```

### 4.1 链语法（v1.9 拍板）

`--preprocess` 接受**逗号分隔的子串**，每个子串 = op 名（可选 `=参数`）：

| op token | 别名 | 参数语法 | 默认（balanced）|
|----------|------|----------|----------------|
| `sharpen` | `sharp` | `=amount` (float) | amount=1.5 |
| `denoise` | `dn` | `=h` (int) | h=7 |
| `clahe` | `cl` | `=clip` (float) | clip=2.0 |
| `gamma` | `gm` | `=value` (float, >0) | value=1.2 |

示例：
```bash
--preprocess "sharpen=2.0,denoise=10,clahe=3.0,gamma=1.3"
```

不传 `=value` → 用默认 + 当前 quality 档的隐含值。

### 4.2 质量档

`--preprocess-quality {fast,balanced,best}`（默认 `balanced`）：

```bash
--preprocess-quality fast      # PIL 内置，零 OpenCV 调用
--preprocess-quality balanced  # cv2 默认参数（默认）
--preprocess-quality best      # cv2 高质量参数
```

环境变量覆盖：`BOOKCUT_PREPROCESS_QUALITY=fast|balanced|best`（与 `BOOKCUT_BINARIZE` 同一模式）。

### 4.3 顺序语义

链中 op **按声明顺序** 应用（从左到右）。例如：
- `gamma,sharpen`：先调亮 → 再锐化（暗→亮的过渡更平滑）
- `denoise,sharpen`：先清噪 → 再锐化（避免放大噪点）✅ 推荐
- `clahe,sharpen`：先展对比 → 再锐化（CLAHE 后噪点可能被放大；用户自负）

文档明确写"推荐顺序"：denoise → clahe → sharpen → gamma（最后调亮度最稳）。

### 4.4 dry-run 集成

`--dry-run --preprocess ...` 自动出 4 联对比图：

```
[原始 RGB] | [preprocess 后] | [deskew 后] | [最终 binarize 后]
```

复用 v1.8 dry-run 的拼图基础设施（`pipeline/dry_run.py`），
**只在用户同时启用 `--preprocess` 才加第 2 列**（节省默认 dry-run 时间）。

## 5. 模块设计

### 5.1 新增文件

├── sharpen.py         # NEW

每个文件结构（以 `sharpen.py` 为例）：

```python
"""锐化（v1.9+）：unsharp mask。

三档实现：
- fast:    PIL.ImageFilter.SHARPEN（3×3 锐化核）
- balanced: cv2.GaussianBlur + addWeighted（amount=1.5, radius=1.0）
- best:    cv2.GaussianBlur + addWeighted（amount=2.0, radius=1.5）
"""

from __future__ import annotations
import os
import platform
from PIL import Image, ImageFilter
import cv2
import numpy as np

_QUALITY = os.environ.get("BOOKCUT_PREPROCESS_QUALITY", "balanced").lower()


def sharpen_from_array(arr: np.ndarray, amount: float = 1.5, radius: float = 1.0) -> np.ndarray:
    """核心：接受 ndarray(float32 或 uint8)，返回 ndarray(同 dtype)。"""
    if _QUALITY == "fast":
        # PIL SHARPEN 是 uint8 only；走 Image 路径更稳
        img = Image.fromarray(arr.astype(np.uint8), mode="L")
        return np.asarray(img.filter(ImageFilter.SHARPEN), dtype=arr.dtype)
    # balanced/best：unsharp mask
    blurred = cv2.GaussianBlur(arr, (0, 0), radius)
    return cv2.addWeighted(arr, 1.0 + amount, blurred, -amount, 0)


def sharpen(image: Image.Image, amount: float | None = None) -> Image.Image:
    """PIL Image wrapper：自动处理 RGB/L 模式。"""
    arr = np.asarray(image.convert("L") if image.mode != "L" else image, dtype=np.uint8)
    if amount is None:
        amount = {"fast": 1.0, "balanced": 1.5, "best": 2.0}[_QUALITY]
    out = sharpen_from_array(arr, amount=amount)
    return Image.fromarray(out, mode=image.mode if image.mode == "L" else "L")


def sharpen_chain_token(token: str) -> tuple[str, float]:
    """解析 'sharpen' 或 'sharpen=2.0' → ('sharpen', 2.0)。"""
    if "=" in token:
        name, val = token.split("=", 1)
        return name.strip(), float(val)
    return token.strip(), float("nan")  # NaN = 用 quality 默认
```

类似地写 `denoise.py` / `clahe.py` / `gamma.py`。

### 5.2 dispatcher（`preprocess/__init__.py`）

```python
def preprocess(
    image: Image.Image,
    chain: list[str],
    quality: str = "balanced",
) -> Image.Image:
    """v1.9+ 流水线预处理 dispatcher。

    Args:
        image: 输入图像（任意模式）。
        chain: ['sharpen', 'denoise=10', 'clahe=2.0', 'gamma=1.2'] 之一。
        quality: fast | balanced | best（仅当 chain 中 op 未显式传参时生效）。

    Returns:
        处理后的 Image（mode 与输入相同）。
    """
    if not chain:
        return image
    for token in chain:
        op, val = _parse_token(token)  # 复用各模块的 *_chain_token
        if op in ("sharpen", "sharp"):
            image = sharpen(image, amount=_resolve("sharpen", val, quality))
        elif op in ("denoise", "dn"):
            image = denoise(image, h=_resolve("denoise", val, quality))
        elif op in ("clahe", "cl"):
            image = clahe(image, clip=_resolve("clahe", val, quality))
        elif op in ("gamma", "gm"):
            image = gamma(image, value=_resolve("gamma", val, quality))
        else:
            raise ValueError(f"未知预处理 op: {op!r}（合法: sharpen/denoise/clahe/gamma）")
    return image
```

## 7. 风险与权衡

| 风险 | 等级 | 缓解 |
|------|------|------|
| 新功能破坏 A1 单次 RGB→L 优化（多 1 次 convert("L")） | 中 | preprocess 在 PIL 上做（不进 arr 路径），与 A1 不冲突；性能测试验证 < 5ms/页（fast）/ < 30ms/页（balanced） |
| cv2 不可用（理论上 requirements 锁了，防御性写） | 低 | denoise/clahe/gamma 检测 `cv2 is None` → 退到 PIL fast；或 raise 清晰错误 |
| CLAHE 在 RGB 上无意义（必须 L） | 低 | 内部统一 convert("L")，结果回 mode=L；下游 binarize 已支持 L 入 L 出 |
| Gamma < 1 / > 4 极端值导致全黑/全白 | 低 | clamp `value ∈ [0.25, 4.0]`，out-of-range raise |
| `--preprocess` 链顺序错（如 `sharpen,denoise`）用户责任 | 低 | 文档明确推荐顺序；不强制校验 |
| GUI preset 列表不全 | 低 | 6 个常用 preset + custom；用户用 custom 即可 |
| dry-run 4 联对比图渲染开销 | 低 | 仅当 `--dry-run --preprocess ...` 同时启用才加；fast 模式不加（避免 cv2 依赖） |
| 与 v1.8.2 trim 鲁棒性补丁交互 | 低 | trim 仍看 ink 像素；preprocess 后 ink 像素可能略增（CLAHE/sharpen 强化墨迹）；用 paper color 自适应抵消 |
