# v2.1 trim A+B 提案：二值化 trim source + CCA 主体过滤

> 状态：🚧 实验阶段（branch `v2.1-trim-ab`，2026-06-24）

## 1. 背景与问题

### 1.1 用户反馈

> "目前切白边的效果不是很好，会存在大量无效部分保存。"

### 1.2 实测 baseline（`samples/尸子卷上下.浙江书局.光绪三年刊_0021.png`）

```
原图：6400×8534 (mode=L)
裁后：4947×7610（裁掉 31.1% 像素）
裁后 ink ratio：5.76% → 8.36%（密度提升，但仍有大量白边）
```

**边缘分析**：

| 边 | 原图前 100px dark ratio | 裁后前 100px dark ratio | 诊断 |
|----|----------------------|----------------------|------|
| top | 0.00% | 2.73% | 干净但仍贴边墨迹 |
| bottom | 0.00% | 3.96% | 干净但仍贴边墨迹 |
| **left** | **9.44%** | **10.58%** | **贯穿全页墨迹贴边 → safety 命中** |
| right | 0.00% | 0.01% | 干净 |

**关键发现**：左边 100px 有墨迹，**7398/8534 行（86.7%）有 ink** → 这是版框左边线（贯穿全页的 vertical line，h≈7000×w≈5）。

### 1.3 根因

当前 `_trim_margins_from_array` 的 bbox 逻辑：

```python
ink_mask = arr < ink_thr               # 全局单阈值
rows_idx = np.where(row_has_content)[0]  # 找第一个"有内容"的行
cols_idx = np.where(col_has_content)[0]  # 找第一个"有内容"的列
top, bottom = rows_idx[0], rows_idx[-1]
left, right = cols_idx[0], cols_idx[-1]
```

**4 个根本问题**：

| # | 问题 | 在尸子图上的体现 |
|---|------|-----------------|
| 1 | 版框线被当成"墨迹"内容 | bbox 从 col 0 开始，左边白边永远裁不掉 |
| 2 | safety margin（40px）贴边即放弃 | 内容贴边 → 整图保留 |
| 3 | 不分"主体"与"杂质" | 边角噪点、版框线、注释横线同等对待 |
| 4 | paper color 估计误差 | 灰阈值对泛黄/暗角鲁棒性差（虽然本图 paper=255 不偏） |

## 2. 目标

在不破坏现有行为（向后兼容）的前提下，新增两个**opt-in**参数：

| 参数 | 类型 | 默认 | 作用 |
|------|------|------|------|
| `trim_source` | `Literal["gray", "binarized"]` | `"gray"` | A：trim 的 ink mask 来源（灰度图 vs 二值图） |
| `min_component_ratio` | `float` | `0.0` | B：CCA 主体过滤，单个连通区面积 ≥ ratio × 总 ink 面积 才算主体 |

CLI 入口：
- `--trim-source {gray,binarized}`（默认 gray）
- `--trim-min-component-ratio 0.005`（默认 0 = 关闭 CCA 过滤）

## 3. 方案 A：二值化 trim source

### 3.1 思路

`trim` 当前用灰度 `< ink_thr` 做 ink mask。改为：用 `binarize(arr, method=...)` 的二值输出做 ink mask。

**优势**：
- 二值图 paper 严格 = 255、ink 严格 = 0，**paper color 估计误差无效**
- 抗暗角（暗角灰度 < paper_color → 被识别成 ink；二值图里暗角仍 = 255 paper）
- 抗扫描不均（局部 paper 偏黄 → 二值化能局部适应）
- 复用 binarize 已有的 Sauvola 路径（古籍泛黄首选）

### 3.2 实现

在 `_trim_margins_from_array` 里：

```python
if trim_source == "binarized":
    # 走 binarize 路径拿二值图（无副作用，不影响后续 binarize 步骤）
    bin_img = binarize(arr, method="otsu", binary_mode="8bit")  # 或 sauvola
    ink_mask = np.asarray(bin_img.convert("L")) < 128
else:
    ink_mask = arr < ink_thr
```

**注意**：
- binarize 默认 `binary_mode="1bit"`（v2.0+），但 trim 内部需要 uint8 ndarray，所以传 `"8bit"`
- binarize 输出再转灰度 → 转 mask（`< 128` = ink）

### 3.3 风险

| 风险 | 缓解 |
|------|------|
| binarize 调用 ×2（trim 内 + pipeline 后） | trim 内 binarize 复用 pipeline 的 binarize 缓存（v2.1 候选） |
| binarize_method 用户没指定时怎么办 | trim_source="binarized" 强制 method="otsu"（快 + 通用），sauvola 用 `trim_source_method="sauvola"` 单独控制 |
| 二值化失败/超时 | fallback 到原 gray 路径 |

## 4. 方案 B：CCA 主体过滤

### 4.1 思路

连通域分析（Connected Component Analysis, CCA）→ 找面积 top-N 的"主体"连通区 → 用它们的并集 bbox 作为 trim 框。

**为什么 CCA 能解决版框线问题**：

| 连通区 | 形状 | 面积 |
|--------|------|------|
| 版框左边线 | h≈7000 × w≈5 | ~35,000 px²，aspect ratio ~1400:1 |
| 单个汉字 | h≈80 × w≈80 | ~3,000-6,000 px²，aspect ratio ~1:1 |
| 一行字符连通区 | h≈80 × w≈400 | ~30,000 px²，aspect ratio ~5:1 |
| 边缘噪点 | 单像素/小块 | <100 px² |

用 `aspect_ratio` 或 `area` 阈值都能区分。但更稳的是用**面积比例**：`min_component_ratio=0.005` → 6400×8534 图上要求 ≥ 27,000 px² → 版框线 ~35,000 仍过线（但顶多 2 条），单个字符 < 6,000 不过线。

**更稳的策略**：取累计面积 ≥ 80% 的 top-N 连通区作为主体。或：先滤掉面积 < min 的，再取 bbox。

### 4.2 实现

```python
def _filter_main_components(ink_mask, min_area):
    """滤掉小连通区，返回主体 mask。"""
    if min_area <= 0:
        return ink_mask
    n_labels, labels, stats, _ = cv2.connectedComponentsWithStats(
        ink_mask.astype(np.uint8), connectivity=8
    )
    if n_labels <= 1:
        return ink_mask
    # stats[i] = [x, y, w, h, area]
    keep = np.zeros_like(ink_mask, dtype=bool)
    for i in range(1, n_labels):  # 0 = background
        if stats[i, cv2.CC_STAT_AREA] >= min_area:
            keep[labels == i] = True
    return keep
```

`min_area = min_component_ratio * ink_mask.size`

### 4.3 风险

| 风险 | 缓解 |
|------|------|
| 连通区面积阈值太严 → 误杀真字符 | ratio 默认 0 → 不启用；建议 0.005-0.01 |
| 版框线面积也很大 → 仍被保留 | ratio 0.005 时 6400×8534 → 27k px²，版框线 35k 仍过线。**用 aspect_ratio 二次过滤**：`h/w > 10` 或 `w/h > 10` → 视为版框线/注释横线，剔除 |
| 极稀疏墨迹（每页 < 10 字符）→ 全被滤掉 | fallback：若所有连通区都 < min_area → 返回原 mask |

## 5. 组合：A + B

两者独立，互不依赖：

- **A** 改 ink mask 的**来源**（灰度 vs 二值）
- **B** 改 ink mask 的**内容**（保留所有 vs 仅主体）

组合 = 二值 mask 上做 CCA 主体过滤。

预期对尸子图的效果：
- A：版框线保留为 ink（因为它是 ink）
- B：版框线被 aspect_ratio 过滤
- 组合：紧贴文字 bbox

- **风险 1**：CCA aspect_ratio 阈值不稳（古籍版框线粗细不一）

- **风险 2**：binarize 内部调用增加 ~50-200ms/页
  - **回退**：默认 gray，二值化只 opt-in
- **风险 3**：改默认后回归老样本
  - **保留**：两个参数都默认旧行为，必须显式开启
