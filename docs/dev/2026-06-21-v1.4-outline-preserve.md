# 2026-06-21 · book-cut v1.4 PDF outline 保留（提案）

> 状态：提案，未实现
> 分支：`v1.4-outline-preserve`（待创建）
> 拍板：方案 D（pypdf 后处理）+ `--page-order` 开关 + 1:2 只指第一张 + page labels 推迟

## 1. 目标

古籍扫描件 PDF 经常带 outline（书签/目录）：卷一、卷二、章、节等。
当前 `book-cut` 切分 + img2pdf 合并后，outline **完全丢失**——生成的 PDF 在 PDF 阅读器里看不到任何目录导航。
v1.4 把 outline 透传到输出 PDF，同时透传 metadata（标题/作者/creator 等）。

## 2. 现状与根因

三层断点（见 `io/loader.py:46-60` / `pipeline.py:82-138` / `io/exporter.py:47-57`）：

1. **加载层**：`pymupdf.open()` → `page.get_pixmap()`，outline/metadata/named-dests/page-labels **全部丢弃**
2. **处理层**：`PageInfo(image, source_name, page_index)` 没有指向 outline 的指针
3. **导出层**：`img2pdf.convert()` 是"图→PDF"工具，**无 outline API**

页数变化加剧：原 1 页跨页图 → 切 1 张或 2 张 → 输出 PDF 页数 ~2×，即使拿到 outline 也需要页号重映射。

## 3. 候选方案（已比较）

| 方案 | 思路 | outline | metadata | 图片质量 | 改动量 | 评估 |
|------|------|---------|----------|----------|--------|------|
| A. 不处理 | 现状 | ✗ | ✗ | 无损 | 0 | 失效 |
| B. PyMuPDF 全程重写 | 弃 img2pdf，pymupdf 重写 | ✓ | ✓ | **有损** | 中 | 破坏 v1.3 验证 |
| C. 改原 PDF 插入 | `insert_page` 替换原页 | ✓ | ✓ | 有损 | 大 | 页号偏移难处理 |
| **D. pypdf 后处理** | img2pdf 出无 outline PDF → pypdf 注入 | ✓ | ✓ | 无损 | **小** | **采用** |

**D 方案核心**：保留 img2pdf 的"无损合并"，用 pypdf 做"轻量后处理"——开 PDF、改 outline/Info、改完关 PDF。

## 4. 数据流

```
1. 加载（如输入是 PDF）：
   doc = pymupdf.open(pdf_path)
   toc = doc.get_toc()              # [[lvl, title, page_1idx], ...]
   metadata = doc.metadata          # {title, author, subject, ...}
   # PageInfo 增加字段：toc / pdf_metadata（图片输入为 None/{}）

2. 切分（pipeline 维护 mapping）：
   mapping: dict[orig_idx_0based, list[out_idx_0based]]
   - 单页检测命中  →  mapping[i] = [j]
   - 双页正常      →  LTR: mapping[i] = [j, j+1]
                     RTL: mapping[i] = [j+1, j]   # 右先左后

3. img2pdf 写出无 outline 中间 PDF
   /tmp/bookcut_xxx.pdf

4. pypdf 后处理：
   reader = pypdf.PdfReader(tmp)
   writer = pypdf.PdfWriter()
   writer.append_pages_from_reader(reader)
   if not args.no_outline and toc:
       for lvl, title, orig_page_1idx in toc:
           out_first = mapping[orig_page_1idx - 1][0]
           writer.add_outline_item(title, out_first, level=lvl)
   if metadata:
       writer.add_metadata({k: v for k, v in metadata.items()
                            if k in STANDARD_METADATA_KEYS})
   writer.write(final_pdf)
```

## 5. 关键设计

### 5.1 PageInfo 扩展

```python
@dataclass
class PageInfo:
    image: Image.Image
    source_name: str
    page_index: int
    # 新增：仅 PDF 来源有值
    pdf_toc: list[tuple[int, str, int]] | None = None      # 来自 doc.get_toc()
    pdf_metadata: dict[str, str] | None = None              # 来自 doc.metadata
    # 注意：原 PDF 的 toc 是"全文档级"，每页都复制一份是浪费 → 不在 PageInfo 里
    # 改为：迭代器维护一个 PdfContext，单次打开 doc
```

**修正方案**：PageInfo 不带 toc/metadata。改用 `_iter_pdf` 返回 `(PageInfo, PdfContext)` 元组，或维护闭包状态。
为最小化接口变化，**最终采用**：

```python
def _iter_pdf(pdf_path, dpi=300) -> Iterator[PageInfo]:
    doc = pymupdf.open(pdf_path)
    toc = doc.get_toc()                   # 全文档 toc
    metadata = doc.metadata               # 全文档 metadata
    # 把 toc/metadata 挂到 doc 上，由 caller 决定怎么用
    doc._book_cut_toc = toc               # 临时挂载
    doc._book_cut_metadata = metadata
    try:
        ...
        yield PageInfo(...)
    finally:
        doc.close()
```

调用方需要 toc/metadata 时，自己开一次 doc（开销 ~ms 级），不污染 PageInfo 抽象。

### 5.2 Page order（`--page-order`）

| 值 | 行为 | 适用 |
|----|------|------|
| `ltr`（默认）| 左先右后，outline 指向左 | 简体横排、装订从左到右 |
| `rtl` | 右先左后，outline 指向右 | 繁体竖排、装订从右到左（**古籍主流**） |

实现：在 `_split` 后用 `[image.crop((x,0,w,h)), image.crop((0,0,x,h))]` 反转，或在 pipeline 里加一个 `apply_page_order(sub_pages, order)` 包装。

### 5.3 Outline 1:2 映射规则

1:2 切分时，outline 指向**第一张**输出页（用户拍板）：

```
原 PDF page 5 outline "卷二" → 输出 PDF page 9（左）或 page 10（右，依 page_order）
                              只指第一张，第二张无 outline 节点
```

实现：取 `mapping[i][0]`（list 的第一个元素）。

### 5.4 Metadata 透传

`pymupdf.Document.metadata` 返回的 keys（`/Info` 字典）：

```python
STANDARD_METADATA_KEYS = {
    "title", "author", "subject", "keywords", "creator", "producer", "creationDate", "modDate"
}
```

一律透传，并把 `producer` 追加 `"; book-cut {__version__}"` 以示出处。

### 5.5 多 PDF 源

`--input` 是文件夹含多个 PDF 时：
- **本版本简化策略**：只保留**第一个 PDF** 的 outline + metadata（拼合多 outline 树语义模糊，留 v1.5+）
- 启动日志提示 `[WARN] 检测到 N 个 PDF 输入；outline 仅保留第一个：xxx.pdf`

## 6. CLI 改动

```python
# 新增
parser.add_argument(
    "--page-order",
    choices=["ltr", "rtl"],
    default="ltr",
    help="1:2 切分时输出顺序：ltr=左先右后（默认）/ rtl=右先左后（古籍竖排）",
)
parser.add_argument(
    "--no-outline",
    dest="outline",
    action="store_false",
    default=True,
    help="关闭 outline / metadata 透传（仅 PDF 输入 + --pdf 模式有效）",
)
```

> 注意：`--no-outline` 同时关闭 metadata 透传（不区分）。命名上保持"outline"以匹配用户心智。

## 11. 风险

| 风险 | 缓解 |
|------|------|
| pypdf 与 pymupdf 共存版本冲突 | 锁定版本；pypdf>=4 与 pymupdf>=1.23 无重叠依赖 |
| 1:1/1:2 混合时 mapping 缺失某原页 | 防御：mapping 兜底为 `[j]`（指向现有 page） |
| 巨型 outline（>1000 节点）拖慢 pypdf | 实际古籍 < 100 节点；如有需要再优化 |
| 多 PDF outline 合并语义模糊 | 本版本只保留第一个，log 警告；v1.5 再做合并 |
| page labels（罗马数字）| **不做**（拍板推迟到 v1.4 后） |
| 跨平台打包 | pypdf 纯 Python，PyInstaller 自动识别；spec 加 hiddenimports 保险 |

## 12. 已知限制（v1.4 范围外）

1. **page labels**（罗马数字 → 拆分）→ v1.5
2. **多 PDF outline 智能合并** → v1.5
3. **named destinations 透传**（pypdf 自动转，但未单独测）→ 本版本随 outline 一起走
4. **outline 节点指向**"左" / "右"标注（如"卷二（右）"）→ 不做（拍板"只指第一张"）
