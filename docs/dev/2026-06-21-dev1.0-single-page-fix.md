# 2026-06-21 · dev1.0 单页检测误判修复

## 起点

跑 v1.1 默认配方（`--split gutter --crop border --binarize sauvola`）处理
`ZHSY100456_醉翁琴趣外篇_宋歐陽修撰_清初影宋抄本.pdf`（66 页），
发现**封面（page 1）被错判为单页**，整页只输出 1 张图，而非左右两张。

### 用户反馈

> 该书是双页扫描的。识别算法是否有误

封面场景：左边是衬纸（白），右边是红色印刷封面（浓墨）。
旧算法 `min/max < 0.1` 把"一边几乎空白"判为单页，把封面也吞了。

## 数据收集

跑了一份诊断脚本，把 ZHSY PDF 关键页的"墨迹占比 / 中缝 / 两侧均值"全打出来：

| page | size     | gutter_x | L_ink  | R_ink  | min/max | L_mean | R_mean | L_med | R_med |
|------|----------|----------|--------|--------|---------|--------|--------|-------|-------|
| 1    | 1500x1008 | 645      | 0.0000 | 0.7000 | 0.0000  | 255.00 | 136.28 | 255.0 | 73.0  |
| 2    | 1025x933  | 512      | 0.0286 | 0.0604 | 0.4740  | 213.93 | 211.20 | 217.0 | 217.0 |
| 3    | 1025x820  | 512      | 0.0286 | 0.0287 | 0.9970  | 213.91 | 214.09 | 217.0 | 217.0 |
| 15   | 1025x756  | 512      | 0.1996 | 0.2068 | 0.9649  | 194.53 | 194.41 | 217.0 | 217.0 |
| 66   | 1025x676  | 512      | 0.1135 | 0.1539 | 0.7373  | 206.62 | 200.92 | 217.0 | 217.0 |

观察：
1. **page 1（封面）的左侧 mean = 255.0（中位数 255）**——是"纯白衬纸"，不是扫描台。
2. **page 1 的右侧 mean = 136（中位数 73）**——是红色印刷，墨迹极浓（70%）。
3. page 2 ~ page 66 都是正常的双页文本：两侧 mean 都在 195-215，median 217（纸色）。
4. 文本页双侧 ink 比都 ≥ 0.47（min/max），只有封面 min/max = 0。

## 旧算法（v1.1）

```python
def is_single_page(image, gutter_x, ratio_threshold=0.1):
    ...
    return min(left_ratio, right_ratio) / max(left_ratio, right_ratio) < ratio_threshold
```

**问题**：只看"两侧墨迹比"，不分"空白侧是纸还是扫描台"。封面（白纸 + 浓墨）触发判据，误报为单页。

## 候选修复（按尝试顺序记录）

### 方案 A：要求两侧都"几乎空"才判单页

```python
return (left_ratio < absolute_blank) and (right_ratio < absolute_blank)
```

思路：真单页 = 飞叶 / 纯空白页 = 两边都没墨迹。
封面 = 一边有 70% 墨迹 → 不是单页 → 不被吞。

**问题**：放弃对"扫描台/校色卡在一边"的检测。如果用户扫描时
一边是单页页 + 另一边是灰色扫描台（mean ~ 180），新算法不报单页了。
旧算法会报单页（因为 min/max < 0.1）。这是行为回退。

**否决**：单页检测功能退化成"只检测全空白页"，不如直接删掉。**❌**

### 方案 B：要求"墨迹极浓"才不算单页（max 阈值）

```python
if max(left_ratio, right_ratio) > 0.5:
    return False  # 浓墨一边说明是封面/插页，不算扫描台
return min(left_ratio, right_ratio) / max(left_ratio, right_ratio) < ratio_threshold
```

思路：封面有浓墨（70%），max > 0.5 → 视作 spread；正常单页 max < 0.5 → 仍判单页。

**问题**：阈值 0.5 是经验值。
- 浓墨插页（max=0.55）会被错误地保留为 spread——可能是对的，也可能是错的。
- 整页图版（古籍版画）经常 max > 0.5，被保留为 spread 是合理行为。
- 但古籍"全黑边栏"也可能 max > 0.5，行为变模糊。

**否决**：依赖 max 阈值太脆。换本书（max 分布变了）就要重调。**❌**

### 方案 C：检查"空白侧"是不是纸 ✅ 选定

```python
# 旧判据
if min/max >= ratio_threshold:
    return False
# 新增：检查空白侧
if left_ratio < right_ratio:
    empty_mean = float(arr[:, :gutter_x].mean())
else:
    empty_mean = float(arr[:, gutter_x:].mean())
if empty_mean >= paper_min_mean:  # 240
    return False  # 空白侧是纸 → 跨页里的空白页
return True  # 空白侧不是纸 → 真正的单页扫描
```

核心思想：

- 真正的单页扫描 = 空白侧是**扫描台/校色卡**，色值偏离纸色（mean < 240）。
- 跨页里的空白页 = 空白侧是**衬纸/纸色**，mean ≈ 255。
- 加这条纸色判断就把两种情况分开了。

为什么是 240？
- 衬纸是 255（中位数 255）。
- 扫描台常是灰色（~200）或校色卡（彩色或 18% 灰 ~118）。
- 纸色 217（中位数）出现在有少量墨迹的页，但 mean < 240。
- 240 留出安全区：纸色 + 少量底灰都能过，但纯白衬纸也能识别。

**验证（ZHSY 全部 66 页）**：
- page 1：L_mean=255 ≥ 240 → 不判单页 ✓
- page 2~66：min/max ≥ 0.47，第一道关就过 → 不判单页 ✓
- 假设的"白台扫描"：L_mean=255 ≥ 240 → 不判单页（和旧行为不同，但用户的 `samples` 里没这种数据，**用 `--no-single-page` 兜底**）。
- 假设的"灰台扫描"：L_mean=180 < 240 → 判单页 ✓（旧行为保留）

**确认采纳** ✅

## 结论

dev1.0 分支用 `is_single_page` 增加"空白侧纸色检查"解决封面误判：

- ✅ ZHSY 封面正确切 2 张（白衬纸 + 红封面）
- ✅ 茶山集 68 页文本照常 2 张/页
- ✅ 真单页扫描（灰台）仍正确识别
- ✅ 飞叶 / 全空白页 不被误判（max=0 早退）
- ✅ 全部 37 测试过、lint 干净

## 已知限制

1. **白色扫描台**：如果扫描台恰好是白色（部分专业扫描仪），与衬纸无法区分——会被判为 spread。可用 `--no-single-page` 显式覆盖。
2. **`paper_min_mean=240` 是经验值**：极端纸色（很黄/很灰的旧纸）可能误判。可在 `is_single_page` 调用处覆盖。
3. **修复后默认** `is_single_page` 仍开启；不改 v1.1 默认行为（用户没要求）。
